[**rataflow**](https://rataflow.furkankly.dev): Interactive node-based UIs for the terminal.

## 0.1.0 - 2026-08-18

First release.

rataflow is a library for building node-based UIs in the terminal, from a static diagram to a fully interactive editor. Built on [ratatui](https://ratatui.rs), inspired by [xyflow](https://xyflow.com).

Nodes and edges on a canvas you can pan and zoom, with handles, nested nodes, multi-selection, dragging, and connections drawn with the mouse. It reacts only to the input you forward and returns events describing what happened, so it never mutates the graph behind your back.

The crate compiles to WebAssembly as well. Every example runs in the browser at [rataflow.furkankly.dev](https://rataflow.furkankly.dev).
